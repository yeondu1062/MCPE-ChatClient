# MCPE-ChatClient
웹상에서 베드락 마인크래프트 게임내에 접속해 채팅을 할수있는 프로그램입니다.

## 사용법
BDS계열의 구동기에서만 작동합니다.  
[serverAddr](./serverAddr.json) 파일에 서버주소를 입력해주세요.  
 ```json
{
  "host": "kiugi.kro.kr",
  "port": 19132
}
```
초기에 계정 로그인을 콘솔에서 진행해야합니다.
